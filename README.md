# AMIRHOSEIN MOVAZEB | Science 7
وب‌سایت ایستا و فارسی علوم تجربی پایه هفتم.

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید.

## انتشار رایگان روی GitHub Pages
1. یک مخزن جدید در GitHub بسازید.
2. همه فایل‌ها و پوشه‌های این پروژه را در مخزن بارگذاری کنید.
3. در Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
4. شاخه main و پوشه root را انتخاب و ذخیره کنید.

## فایل‌ها
- `assets/science7-book-1405.pdf`: کتاب کامل
- `assets/science7-notes.pdf`: جزوه
- `assets/science7-activities.pdf`: پاسخ فعالیت‌ها و آزمایش‌ها

نکته: صفحات فصل‌ها فعلاً چارچوب اولیه هستند؛ محتوای کامل و دقیق هر فصل باید با صفحات کتاب تطبیق داده و تکمیل شود.
